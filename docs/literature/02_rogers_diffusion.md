# Rogers — Diffusion of Innovations

**Claim.** Adoption is a staged process (knowledge → persuasion → decision → implementation → confirmation), and adopter categories differ in timing; perceived attributes (relative advantage, compatibility, complexity, trialability, observability) shape the rate of adoption.

**In DSDVC.** The consumer-journey state machine (`conversion/journey.py`, simulator stages) borrows the staged framing; observability motivates STEPPS 'Public'.

**Not established.** Transition probabilities or the specific DSDVC stage boundaries — these are estimated per transition from data.

## References
- Rogers, E. M. (2003). Diffusion of Innovations (5th ed.). Free Press.
